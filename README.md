# Student-Social-Media-Addiction-Analysis
Power BI dashboard analyzing student social media usage, addiction, mental health, sleep, academic impact, relationships, and conflicts.

## 📌 Overview

This project uses Power BI to analyze social media usage and its relationship with student addiction, mental health, sleep, academic performance, relationships, and social media conflicts. The dashboard provides interactive views across student demographics, lifestyle factors, academic impact, relationships, and individual student profiles.

## 📂 Repository Files

* `student_social_media_addiction.pbix` — Power BI dashboard containing the complete data model, visuals, filters, and interactive analysis.
* `students_social_media_addiction.xlsx` — Source dataset used for the analysis.
* `README.md` — Project overview, techniques, insights, and recommendations.

## 🛠️ Key Techniques

* Data modeling using multiple tables
* Data transformation and preparation
* Relationships between student and behaviour data
* DAX measures and calculated metrics
* KPI cards for key performance indicators
* Interactive slicers and filters
* Bar, column, line, pie, donut, scatter, and table visuals
* Drill-through and student-level profile analysis
* Bookmarks and bookmark navigation
* Analysis by age, gender, academic level, country, and relationship status
* Comparative analysis of usage, addiction, sleep, mental health, and academic impact

## 🔍 Key Insights

* 705 students were analyzed, with 453 reporting that social media affects their academic performance.
* Instagram was the most-used platform, followed by TikTok and Facebook.
* Higher daily social media usage was associated with higher addiction scores.
* Higher addiction scores were associated with lower mental health scores and fewer hours of sleep.
* Social media conflicts showed a strong relationship with addiction scores.
* High school students had the highest average daily usage and addiction score among the academic levels.
* The dashboard allows individual student profiles to be explored using interactive filters.

## 💡 Recommendations

* Encourage students to monitor and manage daily social media usage.
* Promote healthy sleep habits alongside responsible social media use.
* Identify students showing high addiction and conflict levels for targeted support.
* Encourage academic institutions to create awareness programs around excessive social media use.
* Use student-level and demographic insights to design targeted interventions.
* Regularly monitor social media usage and academic impact to identify changing patterns.
